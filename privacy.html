Privacy Policy

Last updated: October 1, 2026

What this app is

Health Sync is a personal tool used only by its owner. It is not available to other users.

Data accessed

With the owner's consent, the app reads the owner's own health and fitness data from the Google Health API using read-only permissions: activity and fitness, health metrics and measurements, and sleep.

How data is used

The data is used only to generate a private progress dashboard for the owner. It is stored on the owner's own computer.

Sharing

The data is not sold, shared with, or transferred to any third party, and is not used for advertising.

Google API Services User Data Policy

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Deleting data

Access can be revoked at any time at myaccount.google.com/permissions. Locally stored data can be deleted by the owner at any time.
